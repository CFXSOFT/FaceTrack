¿usar esta foto como ícono de perfil?

el sistema guarda dos imágenes distintas para cada persona:

  • fotografía facial: se usa únicamente para que la cámara reconozca el rostro y registre la entrada o salida.
  • ícono de perfil: es la imagen pequeña que aparece en la lista de personal, en reportes y en el calendario, para identificar rápido a cada persona.

puedes usar la misma fotografía que acabas de capturar también como ícono, para no tener que subir una imagen aparte. Si prefieres una foto distinta (más profesional o con mejor encuadre), puedes subir otra desde el cuadro de "ícono de perfil".
